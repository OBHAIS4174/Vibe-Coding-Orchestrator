# Vibe Coding Orchestrator: Antigravity Guidelines

When running in an Antigravity workspace, the agent must adhere to the **Vibe & Verify** engineering protocol:

1. **Phase 0: Grilling & Depth Calibration**: Interrogate user requests via a design tree; prompt the user with the 4-level depth calibration rubric before writing any code.
2. **Phase 1: Invariants & Architecture**: Enforce Confirm-Before-Swap, State Isolation, Append-Only history, and zero-downtime database migrations.
3. **Phase 2: Task Graph**: Break features into strictly ordered, decoupled task briefs.
4. **Phase 3: Throwaway Prototyping (Optional)**: Build rapid throwaway UIs to calibrate feel; discard before building.
5. **Phase 4: Test-First (TDD)**: Author failing tests at deep module seams (Red) before writing production code.
6. **Phase 5: Implement & Refactor**: Implement minimum code to pass (Green); apply SOLID principles and deep module boundaries.
7. **Phase 6: Independent Two-Axis Review**: Dispatch read-only reviewer subagents to audit Spec & Security (OWASP).
8. **Phase 7: DevOps QA**: Run full regression suites (`npm test`, `pytest`) and production builds.
9. **Phase 8: Empathy Polish**: Sanitize raw database codes and stack traces into friendly user messages.
